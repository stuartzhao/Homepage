## 主页简介

该网页为安徽工业大学计算机科学与技术学院赵伟教授的个人学术主页。

主页采用静态网页形式，通过 HTML、CSS 和 JavaScript 实现，
主要用于展示个人基本信息、科研方向、论文成果、科研项目、
学生培养以及教学工作等学术信息。
